# RmlUi Unreal

Win64 runtime plugin for RmlUi 6.3 in Unreal Engine 5.8.1. No engine changes.

This repository root is the plugin directory. The surrounding `RmlUiUnrealTest` project is a local test host and is not part of this repository. Generated binaries, intermediate files, native build caches and downloaded archives are excluded; pinned dependency source and Cargo.lock are tracked. Build the bridge before the first Unreal build of a fresh checkout, or use the separately packaged prebuilt plugin.

Place this directory under your project's `Plugins` folder. Build the native bridge once:

```powershell
./Source/ThirdParty/RmlUiBridge/BuildBridge.ps1
```

Then build your Unreal project. Keep `Binaries/ThirdParty/Win64/RmlUiBridge.dll` and `RmlUiBridge.lib` with the plugin. CMake, Visual Studio 2022, a Windows SDK and an MSVC Rust/Cargo toolchain are required to rebuild the native bridge. Pinned sources are bundled under `Source/ThirdParty/RmlUiBridge/vendor` and `grid/vendor`.

Add **RmlUi Document** in the UMG widget palette, or construct `SRmlUiWidget` from C++. Set a document path or inline document source; use Blueprint document events and DOM helpers for application logic. `Tools > RmlUi Preview` opens the editor preview. The inspector is included.

The plugin accepts supported `<html>` or `<rml>` documents with linked `.css` or `.rcss`, images and fonts. RmlUi handles parsing and layout, with native Taffy-backed Grid support added by this plugin. See [Grid support and limitations](GRID_SUPPORT.md) and [RmlUi documentation](https://mikke89.github.io/RmlUiDoc/). It does not embed a browser or JavaScript runtime.

The official full DX11 renderer runs on a private device and supplies pixels to an Unreal texture, so UE may run on DX11 or DX12. Filters, clipping, transforms, layers, masks, shadows and gradients use the upstream renderer. The transport reads pixels to CPU memory and uploads them every frame. This is a functional evaluation backend, not a zero-copy RHI renderer.

The opt-in Slate command renderer avoids the full-view color render target and replays strict 2D affine transforms, nested rectangular scissors, and non-rectangular clip-mask snapshots. ABI v5 publishes geometry and texture create/destroy deltas keyed by stable IDs, so unchanged frames reuse UE-side caches instead of copying complete resources again. Ordinary color and generated-texture draws use `ICustomSlateElement` RDG passes backed by persistent static RHI vertex/index buffers; masked draws rebuild `Set`, `SetInverse`, and `Intersect` operations in a transient depth-stencil attachment without color readback. Creation and deferred destruction run through Unreal's render-resource lifecycle. UE UI material draws deliberately remain on Slate `MakeCustomVerts`, preserving the normal `MD_UI` material pipeline and their ordering with RHI draws. Material draws convert verified filled-convex `Set` and `Intersect` mask geometry into Slate stencil clipping planes, which covers rounded CSS boxes without compiling project materials into the custom RDG shader. Inverse or concave material masks, perspective/3D transforms, layers, filters, and RmlUi shaders remain unsupported and are reported through the frame feature mask. A dedicated ordinary-geometry `SetInverse` pixel fixture, material inverse/concave clipping, and ABI v6 Layer/composite support are explicit roadmap items; future development lint will map these flags back to source HTML/CSS without adding per-node Shipping diagnostics.

The currently verified color contract is SDR sRGB. RmlUi vertex colors and generated/loaded RGBA8 textures carry nonlinear sRGB bytes with RGB premultiplied by alpha in encoded space; generated textures become `SRGB` `PF_B8G8R8A8` Unreal textures. The RHI shader decodes texture and vertex RGB for modulation, encodes its result for the SDR Slate target, and uses premultiplied-alpha blending. UE material vector parameters remain linear `FLinearColor` values and follow the native UI material pipeline. HDR, scRGB/HDR10 output, wide-gamut primaries, alternate render-target formats, and platform output-device transforms are not covered by this contract.

`FRmlUiResourceRegistry` exposes stable-ID snapshots, recursive owner traversal and visitor APIs for native and Unreal-side resource diagnostics. Native View, shared style sheet, Slate geometry/texture/material binding and legacy frame-buffer records are correlated by owner ID; each UE geometry cache owns its RHI vertex/index records, while upload textures and material brushes retain non-owning `TWeakObjectPtr` references for UObjects. Material brushes are reparented when a Widget replaces its native View, so multiple Widget resource trees remain independently enumerable and releasable. Records expose `PendingCreate`, `Live` and `PendingDestroy` states, and visitors run on copied snapshots outside the registry lock. Enable `-trace=RmlUiResources` to record create/update/destroy lifecycle events in Unreal Insights; the channel emits no per-frame events. Requested buffer payload bytes are estimates rather than allocator-level GPU memory. Legacy DX11 tracking is intentionally limited to coarse migration/fallback sentinels and will be removed with that backend, rather than expanded into its private geometry and texture implementation.

Relative resource paths search `Project/Content/RmlUi`, then this plugin's `Content/RmlUi`. Plugin data is staged as UFS. After adding/moving resource files, rebuild with `-NoUBTMakefiles` before packaging so Unreal refreshes wildcard runtime dependencies. Add host project data to Packaging's Additional Non-Asset Directories to Package.

`LoadFontFace` loads custom fonts and optional Unicode fallback fonts. Bundled fonts are Latin; native IME composition and complex-script shaping are not implemented. SVG/Lottie and Lua extensions are not compiled.

Tests are registered as `RmlUiUnreal.*`. `RmlUiUnreal.Slate.RhiDirectRendering` verifies actual RHI output, CSS color space, premultiplied alpha, nested rounded clip-mask pixels, cache readiness, and recursive teardown on both DX11 and DX12 hosts. `RmlUiUnreal.Slate.SdrColorContract` adds deterministic gray/color/transparent PNG pixels, `image-color` modulation, texture format and `SRGB` flags, encoded premultiplied compositing, and an exact MID linear-color parameter probe. `RmlUiUnreal.Resources.MultipleSlateWidgets` verifies per-View DOM and resource isolation, same-name material aliases, peer shutdown, and complete recursive release. `RmlUiUnreal.Resources.MultiWidgetStress` repeats 1/4/8-Widget batches through document reload, material replacement, GC, explicit shutdown and destructor cleanup, and requires every owner tree and replaced/released MID to disappear. The host project's material fixture additionally verifies a registered UI material under rounded clipping. The sample project's root README contains launch, packaging and test commands. Upstream licenses are retained in vendored source and `Content/RmlUi`.
